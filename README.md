# Roblox Scripts Elite

Персональная мастерская Roblox-проектов **Mengy777** · Roblox: **876osamuha**.

Здесь хранятся отдельные скрипты, инструменты разработки, разборы открытых исходников и проверенные инженерные решения. Каждый проект получает собственные настройки, версии и список проверок.

## Навигация

| Каталог | Содержимое |
| --- | --- |
| `projects/` | Отдельные проекты и их документация |
| `shared/` | Общие модули после проверки повторного использования |
| `tools/` | Инструменты разработки и проверок |
| `docs/EXPERIENCE.md` | Практический опыт и известные ошибки |
| `docs/PROGRESS.md` | Фактический прогресс мастерской |
| `docs/SOURCE-REVIEWS.md` | Реестр изученных внешних исходников |
| `templates/PROJECT.md` | Шаблон карточки нового проекта |

## Prime

[Prime Visuals / Prime Vortex](https://github.com/Mengy777/Prime-Script-FTAP) остаются в отдельном репозитории. Здесь используется накопленный опыт их разработки; автоматического переноса кода или изменения релизов нет.

## Подход

Понятный интерфейс, корректное отключение эффектов, устойчивость к респавнам и повторному запуску, проверяемые изменения. Компиляция, симуляция и тестирование в Roblox фиксируются отдельно. Непроверенные возможности не выдаются за готовые.

Для нового проекта сначала определяются игра, назначение и минимальная рабочая версия. Внешние исходники изучаются как текст; лицензии и обязательные уведомления сохраняются.
